CricVault

CricVault is a cricket database management system designed to store, manage, and analyze data from the Indian Premier League. It uses structured DBMS concepts to handle teams, players, matches, and performance statistics efficiently.

📌 Features
Manage teams and player information
Store match details (date, venue, winner)
Maintain the points table
Track player performance (runs, wickets, etc.)
Execute advanced SQL queries for insights

🗂️ Database Structure
Main tables used:
Teams
Players
Matches
PointsTable
PlayerStats
Auction

⚙️ Technologies Used
SQL (MySQL / PostgreSQL)
DBMS Concepts (Normalization, ER Model)
Optional: Java / Python (for frontend/backend)

🔥 Sample Queries
Find Orange Cap holder (most runs)
Find highest wicket taker
Top 4 teams for playoffs
Best all-rounder performance

📊 Project Objective
To design a normalized relational database system that efficiently manages cricket data and enables meaningful analysis through SQL queries.

🚀 Future Enhancements
